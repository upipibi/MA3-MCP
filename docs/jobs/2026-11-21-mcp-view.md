## Proven on onPC 2.5.1.1 by this job

- `Store ScreenContent <screen> "<WindowClass>" "X"="0" "Y"="0" "W"="22" "H"="8"` creates a window
  (a `ViewWidget` with a settings child, `WindowAppearance` and `WindowScrollPositions`); `Set
  ScreenContent 1.1 "W" "22"` resizes it. Units are grid cells of 50 px. The 85 window class names:
  `ShowData().WindowTypes`.
- A pool window's settings are the widget's first child (`ScreenContent 1.1.1`, `PluginPoolSettings`:
  `SHOWEMPTY`, `POOLCOLUMNSCOUNT`, `DATAPOOL`, `ACTION`, colours).
- `Delete View 1 Thru 12`, `Store View 1 "MCP" /Screen "1"`, `Assign View 1 At ViewButton 1.1`: the
  `View` keyword addresses the logged-in user's own profile (`14.19.7.4` here).
- Reading the screen back needs no screenshot: `GetDisplayByIndex(1)` and `UIChildren()` give every
  visible UI object with its `AbsRect` (pixel rectangle); that is how the window placement was checked.
