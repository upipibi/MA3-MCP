## Syntax rules that matter for every command

- Form `[Function] [Object]`; every object has a default function and most functions a default
  object. **A function an object does not support passes to a child or parent object.**
- Keywords are case-insensitive; values in quotes are case-sensitive (`"Positive"` works,
  `"positive"` does not). Single and double quotes nest as pairs.
- Shortcuts: `S Seq 8 Cue 20 /O` = `Store Sequence 8 Cue 20 /Overwrite`, `Co 2 At 6` = Copy.
  **Shortcuts change as keywords are added** (check each version's keyword pages).
- `( ... )` outside quotes opens a text-input pop-up asking the operator for the value (refused by
  the plugin). `;` separates commands. `=` assigns a setting (`Set Macro 3.1 "Enabled" = "No"`,
  `Set Executor 201 "Key" = "Flash"`). `.` separates levels or decimals (`Fixture 31.2`, `At 50.5`).
  `$name` expands a variable (`LogIn $JanePublic`). `%` scales (`At % 50`). `+` / `-` add, remove or
  go relative (`At + 5`, `Group 5 - Fixture 2`). `*` is a wildcard (`Set Macro 5.* Property ...`).
- `Index`: set one entry of a list property, `Set Fixture 1 "Patch" Index 1 "2.1"`, `Set Filter 6
  Property "Attributes" Index 0 "0"`. `Property ... At + Filter "Dimmer Only"` adds a reference.
- `List` and `ChangeDestination` (`cd`) walk the object tree from the command line; `/DiscardChanges`
  on `ChangeDestination Root` drops pending edits; `/NoSubfolders` limits library lists.

## Playback functions on executors and objects

`Flash On/Off Executor 201`, `Temp On/Off Executor 104`, `Black On/Off Executor 201` (master to zero),
`Press` / `Unpress` (`Flash Press Executor 203`), `<<< Sequence 3` and `>>> Executor 103` (go fast
back / forward; also `Page 4`), `DoubleSpeed Sequence 2`, `LearnSpeed` (tap tempo, Learn key),
`FastSync Executor 128` (phaser restarts at step 1 now), `ReSync Executor 128` (phasers drift back
into sync), `FaderCrossFadeA` / `B` (`Assign FaderCrossFadeA At Executor 303`, `FaderCrossFadeB
Sequence 5 At 10`), `Go+ Loaded` / `Off Loaded` (the loaded cue), `Previous`, `Load Previous`,
`Previous Page`, `TopUp` (Set + Up), `Stomp` (`Stomp FeatureGroup "Position"`, `Stomp Group "All
Spots"`: remove values from other playbacks), `Capture` (Stomp twice: take values into the programmer,
`Capture FeatureGroup "Position"`), `KnockIn` (`Fixture 1 KnockIn Attribute "ColorRGB_R"`), `Flip`
(`Flip 2 Group 7`: pan/tilt flip), `Collect Preset 4.2` (collect objects for a later function;
`Move Collection At Preset 4.20`). **All of these act on live output** (`executors-and-pages.md`).

## Running objects (read and stop what plays)

`RunningPlayback`, `RunningSequence`, `RunningMacro`, `RunningPreset`, `RunningTimecode`,
`RunningTimer`, `RunningSoundFile`, and the forms limited to the current user (`MyRunningPlayback`,
`MyRunningSequence`, `MyRunningMacro`, `MyRunningPreset`, `MyRunningTimecode`, `MyRunningTimer`,
`MyRunningSoundFile`): `Off
RunningSequence 1`, `Off MyRunningPlayback`, `ChangeDestination RunningPlayback` then `List`; the
Running Playbacks window filters by `Set RunningPlayback Property "SelectedPlaybackType" "Macro"`
and `"SelectedMine" "Yes"`. A read-only "what is running" answer for a job [?: as an object path].

## Conditions

`If` (selection or condition), `IfActive` (If twice: fixtures with active values), `IfProgrammer`
(If three times), `IfOutput` (`groups.md`), `EndIf` (`Store If Group 5 EndIf Preset 1.1`: the If part
ends before the preset).

## Layers and timing values in the programmer

`At Absolute 10`, `At Relative 10`, `Fade 2`, `At 50 Fade 2`, `Goto Cue 3 Fade 4`, `Delay 4`,
`CueOutDelay 5` (also `Cue 1 Thru 4 CueOutDelay 5`), phaser values `At Acceleration 70`, `At
Deceleration 85`, `At Measure 4`, `At NShot 5`, `At Phase 0 Thru 360`, `At Speed Hz 70`, `At Speed BPM
5`, `At Speed Seconds 20`, `Master 3.1 At BPM 75` (speed masters), `Integrate Preset 1.1 Step 2`
(MA + At: integrate a preset into a phaser step), `Offset` (MA + Update), `DMXLayer`, `OutputLayer`
(sheet layers), `Part` (`Store Cue 3 Part 2`, `Delete Cue 1 Part 3`, `/MoveValues` moves a deleted
part's values).

## Value readouts

`At Absolute Decimal8 255`, `Decimal16 65535`, `Decimal24 1677721`, `Hex8 "FF"`, `Hex16 "FFFF"`,
`Hex24 "FFFFFF"`, `Percent 50`, `PercentFine 50.35`, `Physical 75.60`, `Attribute "Pan" At Natural 26`;
`Readout "Hex8"` and `DMXReadout "Hex8"` change the operator's readout (refused on the console by the
guard). `At ChannelSet 4` calls a channel set.

## Grid helpers

`NextY`, `PreviousY`, `NextZ`, `PreviousZ` step through a multi-row grid selection (`Grid 0/0 Thru
4/4`, `Fixture 1 Thru 25`, `NextY`); `GridPosition` (MAgic grid values, `presets.md`).

## Station maintenance (refused by the plugin)

`CopyCrashLog (If Drive 1)`, `ListCrashLog`, `DumpLog /Limit 10`, `MemoryInfo /Sort "Desc" /Limit 5`,
`ReloadUI`, `SoftwareImport`, `SoftwareUpdate`, `DeleteOtherVersion`, `SwitchTograndMA2Software IP`,
`SwitchTograndMA3Software IP`, `HelpKeyword "Fix*"`, `LuaFile "<path>"`, `ShutDown /NoAutoClose`,
`RemoteCommand ... /Async`. `MemoryInfo` and `ListCrashLog` only print; they are refused only if
their shortcuts collide [C: see `keywords.md`].

## Compact and command-wing keys

`User1` (U1: encoder bar or Xkeys bar) and `User2` (U2: encoder bar or executor bar) exist only on
the compact, compact XT and onPC command wing. Variables: `GetGlobalVariable "f*"` lists global
variables like `GetUserVariable` does for user ones (`macros.md`).

## Chat

`Chat "Cyan is a great color"`, `ChatJoin "Color"`, `ChatLeave "Color"`: messages between users in a
session.
